    Production runs the same Task

    Every 15 minutes the gate checks Jont828's open PRs in ai-dynamo/dynamo. A full run happens every two hours. In between, only a new conflict, a failed check or a due review starts one.

    Shadow mode upstream. Briefs and self-review fixes stay in the run's report until the user switches reviews to live. CodeRabbit threads are still settled: a run fixed a CodeRabbit item on #18618 in 751587a.

    The demos stayed in the fork. A copy of the Task, every 5 minutes, read from and wrote to Jont828/dynamo only, through the gate's SHEPHERD_REPO setting and a preamble that forbids upstream writes.

    Guardrails. It never merges, approves, closes or posts /ok to test. It backs up before any rewrite, pushes with a lease, signs every commit and makes at most one fix commit of each kind per run.

    The terminal replays real commands and their captured output. Typing is simulated, and long waits are shortened and marked ⏩ in the terminal. The browser clips were recorded with Playwright in a logged-out Chrome, so GitHub shows no merge box; the captions were added on the page. Both recordings share one timeline. Each demo was built as its own clip, then the clips were joined.
